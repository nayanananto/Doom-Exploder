# 🚀 DOOM EXPLODER

### Action-Packed Arcade Shooting Game

---

## 🎮 Overview

**DOOM EXPLODER** is a fast-paced, action-packed arcade shooting game where players control a spaceship to destroy incoming asteroids. Designed for casual gamers, the game focuses on simplicity, responsiveness, and engaging gameplay.

---

## 🧠 Inspiration

This project was inspired by classic shooting games like *Gunship Strike Shooting Game*, along with foundational concepts learned during a Software Development course.

---

## 🎯 Features

* 🛸 **Spaceship Control**

  * Move and aim using keyboard controls (W, A, S, D)
  * Shoot using spacebar

* 💥 **Asteroid Destruction**

  * Large asteroids break into smaller ones when destroyed

* 🎚️ **Difficulty Modes**

  * Easy and Hard modes
  * Hard mode yields higher scores

* 🧩 **Multiple Levels**

  * 3 unique levels with increasing difficulty

* ❤️ **Health & Combat System**

  * Spaceship life bar decreases upon collision
  * Missile system (costs 40% health)

* 🏁 **Game Over Mechanism**

  * Restart from current level after death
  * Score resets in Level 1

---

## 🎮 Gameplay Summary

* The spaceship remains centered on screen
* Players control **direction of shooting**, not movement position
* Survive waves of asteroids and maximize score
* Choose strategy between:

  * Continuous shooting
  * High-cost missile attacks
